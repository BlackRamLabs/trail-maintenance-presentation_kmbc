# Reference Documents

The three core reference documents signposted in the Trail Steward Intro
presentation, plus the client-specific Trail Management Plan.

These are stored in the repo so that published links from the presentation
resolve to the actual documents.

## DBCA (state-wide) documents

| File | Referenced as | Used in slides |
|------|---------------|----------------|
| `dbca/western_australian_mountain_bike_management_guidelines.pdf` | WA MTB Management Guidelines | 3 Pillars, Maintenance vs Building, Examples, Trail Closures, Ratings |
| `dbca/Volunteer_WHS_induction_2026.pdf` | DBCA Volunteer WHS Induction | Scope = Shield, Tools, Risk Management, Weather, Code of Conduct, Reporting |
| `dbca/Volunteer Code of Conduct.pdf` | DBCA Volunteer Code of Conduct | Code of Conduct |
| `dbca/trail_development_series_part_a_a_guide_to_the_trail_development_process.pdf` | DBCA Trail Development Process | Maintenance vs Building (context) |

## Client-specific documents

| File | Referenced as | Used in slides |
|------|---------------|----------------|
| `kmbc/250811 Kalamunda Trail Management Plan FINAL.docx` | KMBC Trail Management Plan (Aug 2025) | 3 Reference Documents (4th doc) |

The Kalamunda Trail Management Plan is the club-specific agreement with DBCA.
It covers maintenance cycles, trail closures, volunteer management, incident
reporting, inspection procedures, and the operational framework for the
Kalamunda network. Stewards should know it exists; they don't need to
memorise it.

## Adding a new client's documents

1. Create `reference-documents/<client>/`
2. Copy the client's Trail Management Plan (or equivalent agreement) there
3. The DBCA documents are state-wide — shared across all clients
